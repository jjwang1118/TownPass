| 項目 | 內容 |
| --- | --- |
| **Component ID** | `CM-BTN-01` |
| **名稱** | 朗讀按鈕 |
| **類型** | Button（可點） |
| **使用於** | 長者：`EL-PG-01`、`EL-PG-03`／家屬：`FM-PG-04`（長輩用藥詳情）。`EL-PG-17` 邀請家屬原稿有朗讀按鈕，實作已移除 |
