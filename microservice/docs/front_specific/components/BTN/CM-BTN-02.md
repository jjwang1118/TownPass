| 項目 | 內容 |
| --- | --- |
| **Component ID** | `CM-BTN-02` |
| **名稱** | 主要按鈕 |
| **類型** | Button（可點） |
| **使用於** | 長者：`EL-PG-02`、`EL-PG-07`、`EL-PG-08`、`EL-PG-09`、`EL-PG-10`、`EL-PG-11`、`EL-PG-12`、`EL-PG-13`、`EL-PG-14`、`EL-PG-15`、`EL-PG-16`、`EL-PG-18`／家屬：`FM-PG-01`（使用台北通登入）、`FM-PG-02`（確認綁定）、`FM-PG-06`（打電話給長輩）／救護人員：`RE-PG-01`（登入）、`RE-PG-02`（查詢）、`RE-PG-04`（重新查詢） |
