### CM-ALT-02 推播通知卡

> 來源：Figma「藥報平安」→ `E09｜長者：用藥提醒通知示意`（node `8:1543`）／`E16｜長者：回診提醒通知示意`（node `11:2536`）／`F04｜家屬：用藥提醒通知示意`（node `13:3014`）／`F08｜家屬：回診提醒通知示意`（node `13:3313`，皆同一元件） → `PushNotice`
> 註：這些 Figma frame 其餘內容（手機鎖定畫面時鐘、日期、深色背景）僅為展示情境用，非 App 畫面，不建立 Interface，只記錄此推播卡片本身的規格。

| 項目 | 內容 |
| --- | --- |
| **Component ID** | `CM-ALT-02` |
| **名稱** | 推播通知卡 |
| **類型** | 系統推播通知（可點，於手機系統通知／鎖定畫面顯示，非 App 內頁面元件） |
| **使用於** | 長者：用藥提醒推播（9:00／12:00／18:00／22:00）、回診提醒推播（**回診前 1 小時**，已依討論調整，非 Figma 原稿「回診前一天」）／家屬：同一長輩的用藥提醒推播、回診提醒推播（內容多了長輩姓名與提醒關心的文字） |
| **可見身分／切換** | 長者、家屬皆可收到，樣式相同；內容依「收到的人」切換：長者收到的標題/內文不含姓名，家屬收到的版本在標題加上長輩姓名、內文多一句提醒關心的話 |
| **狀態／變體** | 無（文字內容依通知類型與接收身分動態帶入） |
| **互動** | 點擊 → 開啟 App 並導向對應頁面：用藥提醒 → 該時段用藥詳情（長者：`EL-PG-03`；家屬：`FM-PG-04`，可於該頁聽語音朗讀）；回診提醒 → 回診詳情（ID 待定） |
