### EL-STP-01 數量選擇器

> 來源：Figma「藥報平安」→ `E06b｜長者：修改藥品` → `Stepper`（node `8:1445`／`8:1451`）

| 項目 | 內容 |
| --- | --- |
| **Component ID** | `EL-STP-01` |
| **名稱** | 數量選擇器 |
| **類型** | Stepper（可點） |
| **使用於** | `EL-PG-13`、`EL-PG-14` |
| **狀態／變體** | 依數值顯示（如：半顆／1 顆／2 顆...） |
