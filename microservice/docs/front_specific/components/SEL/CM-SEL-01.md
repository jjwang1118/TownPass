### CM-SEL-01 下拉選單顯示列

> 來源：Figma「藥報平安」→ `E10｜長者：回診預約` → `選單-院區`／`Dropdown`（node `11:2250`／`8:1426`）

| 項目 | 內容 |
| --- | --- |
| **Component ID** | `CM-SEL-01` |
| **名稱** | 下拉選單顯示列 |
| **類型** | Select（可點，點擊開啟 `CM-SH-01` 底部抽屜） |
| **使用於** | 長者：`EL-PG-09`、`EL-PG-10`／救護人員：`RE-PG-01`（所屬單位，單一欄位、無依序鎖定限制） |
| **可見身分／切換** | 長者、救護人員皆可見，樣式相同 |
| **狀態／變體** | 未選（可點，顯示「請選擇」）／已選（可點，顯示選中值，框線變主色）／停用（不可點，顯示「請先選上一項」，底色變灰，僅長者回診預約的依序鎖定情境會用到） |
| **互動** | 點擊（僅未選／已選狀態可點）→ 開啟 `CM-SH-01` 選擇清單；選定後關閉並回填本列顯示值；`EL-PG-09`／`EL-PG-10` 選定後會解鎖下一個欄位，`RE-PG-01` 僅此單一欄位無鎖定關係 |
| **限制** | `EL-PG-09`／`EL-PG-10`：五個欄位（院區／科別／醫師／日期（星期）／時段）依序鎖定，上一欄未選時下一欄為停用狀態，不可跳過或反向選擇；`RE-PG-01`：僅「所屬單位」一欄，無鎖定限制 |
