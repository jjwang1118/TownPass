### EL-INP-02 藥名搜尋

> 來源：Figma「藥報平安」→ `E06b｜長者：修改藥品` → `DrugSearch`（node `90:1490`，元件說明 node `90:1624`）

| 項目 | 內容 |
| --- | --- |
| **Component ID** | `EL-INP-02` |
| **名稱** | 藥名搜尋 |
| **類型** | Input + 即時搜尋結果列表（可點／可輸入） |
| **使用於** | `EL-PG-13`、`EL-PG-14` |
| **狀態／變體** | 空白（尚未輸入，僅顯示輸入框＋範例提示）／有結果（輸入 2 字以上，顯示比對到的藥名清單） |
| **互動** | 輸入 2 個字以上 → 即時比對藥名（WORD MATCH，依輸入內容動態顯示），中英文皆可、不分大小寫比對字首，打中的字加粗；最多顯示 8 筆，北市聯醫常用藥排前面；點擊任一筆結果 → 帶入該藥名並收合清單；找不到時顯示「模擬找不到藥名」提示，引導重新輸入或重新拍藥袋 |
| **限制** | 原型以點擊模擬打字；正式版需串接藥名資料庫 |

**結構與資料**

| 子元素 | 內容／資料欄位 | 範例 |
| --- | --- | --- |
| 輸入框 | 引用 `CM-INP-01`（標籤：藥名（英文或中文都可以）） | Asp |
| 搜尋結果列表 | `results[]`：藥名（打中字加粗）、劑量數、來源說明 | Asp**irin**（阿斯匹靈）／有 3 種劑量｜食藥署許可證資料 |
| 找不到提示 | 固定文字／按鈕 | 模擬找不到藥名（展示用） |
