### CM-INP-01 文字輸入框

> 來源：Figma「藥報平安」→ `E06b｜長者：修改藥品` / `E14｜長者：編輯緊急醫療卡` → `text field/component`（node `I90:1491` 等）

| 項目 | 內容 |
| --- | --- |
| **Component ID** | `CM-INP-01` |
| **名稱** | 文字輸入框 |
| **類型** | Input（可點／可輸入） |
| **使用於** | 長者：`EL-PG-13`、`EL-PG-14`、`EL-PG-16`／家屬：`FM-PG-02`（邀請碼）／救護人員：`RE-PG-01`（人員編號、密碼）、`RE-PG-02`（身分證字號） |
| **可見身分／切換** | 長者、家屬、救護人員皆可見，樣式相同，標籤與鍵盤類型依欄位而定 |
| **狀態／變體** | 必填（左上角有紅點 `mandatory` 標記）／選填（無標記）；正常／**錯誤**（框線變紅 `alarm-default-color-Red/500` #D45251，底下顯示紅色錯誤訊息取代原本的 Help Text，如 `FM-PG-02` 邀請碼輸入錯誤、`RE-PG-02` 查無此身分證字號） |
| **互動** | 點擊 → 聚焦並開啟對應鍵盤（文字／數字／電話依欄位而定）；輸入後即時更新內容 |

**結構與資料**

| 子元素 | 內容／資料欄位 | 範例 |
| --- | --- | --- |
| 必填標記 | 固定圖示（紅點），僅必填欄位顯示 | — |
| 標籤 | `field.label` | 藥名（英文或中文都可以） |
| 輸入框 | `field.value`，無值時顯示 placeholder | 輸入藥袋上的英文或中文藥名 |
| 說明文字（Help Text，選用） | `field.helpText` | 例如：Asp 或 阿斯；錯誤時顯示 `field.errorText`（紅字） |

**本元件於各頁對應欄位**

| 使用頁面 | 欄位（依序） |
| --- | --- |
| `EL-PG-13`／`EL-PG-14` | 藥名（英文或中文都可以，見 `CM-INP-01` 延伸「藥名搜尋」行為） |
| `EL-PG-16` | 姓名、出生年月日、聯絡人姓名、關係、電話、藥物過敏（Help Text：沒有請填「無」）、食物過敏、常去醫院與病歷號 |
| `FM-PG-02` | 邀請碼（共 6 位數字；錯誤文字：邀請碼不正確或已過期，請長輩按「換一組數字」再試一次。） |
| `RE-PG-01` | 人員編號、密碼 |
| `RE-PG-02` | 身分證字號（共 10 碼；錯誤文字：查無此身分證字號的緊急醫療卡，請確認後重新輸入。） |
