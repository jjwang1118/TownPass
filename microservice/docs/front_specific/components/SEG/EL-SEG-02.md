### EL-SEG-02 選項晶片組

> 來源：Figma「藥報平安」→ `E06b｜長者：修改藥品` → `OptionChip`（node `8:1476`／`8:1478`）

| 項目 | 內容 |
| --- | --- |
| **Component ID** | `EL-SEG-02` |
| **名稱** | 選項晶片組 |
| **類型** | Chip group（可點，單選或複選依欄位而定） |
| **使用於** | `EL-PG-13`、`EL-PG-14`、`EL-PG-16` |
| **狀態／變體** | 單選（點擊新選項會取消前一個選項，如：飯前／飯後、性別、血型、慣用語言）／複選（可多選，如：什麼時候吃、慢性病、特殊狀況） |
| **互動** | 點擊晶片 → 切換選中狀態（單選模式下會取消同組其他已選項） |

**結構與資料**

| 子元素 | 內容／資料欄位 | 範例 |
| --- | --- | --- |
| 晶片 | `option.label`，依 `option.selected` 顯示選中樣式 | 早上 |
