### CM-SEG-01 語言切換

> 來源：Figma「藥報平安」→ `E02｜長者：首頁` → `LangSwitch`（node `8:1413`）

| 項目 | 內容 |
| --- | --- |
| **Component ID** | `CM-SEG-01` |
| **名稱** | 語言切換 |
| **類型** | Segmented control（可點） |
| **使用於** | 長者：`EL-PG-01`、`EL-PG-03`／家屬：`FM-PG-04`（長輩用藥詳情） |
| **可見身分／切換** | 長者、家屬皆可見，樣式與互動相同 |
| **狀態／變體** | 國語（選中）／English（選中）。Figma 原稿為國語／台語；手機內建語音沒有台語，實作先改為英文（給外籍看護），台語之後再定 |
| **互動** | 點擊選項 → 切換選中狀態，不會立即觸發朗讀；之後點擊 `CM-BTN-01`（唸給我聽／單顆朗讀）時，會以這裡選中的語言發音 |

**結構與資料**

| 子元素 | 內容／資料欄位 | 範例 |
| --- | --- | --- |
| 選項國語 | 固定文字 | 國語 |
| 選項英文 | 固定文字 | English |
