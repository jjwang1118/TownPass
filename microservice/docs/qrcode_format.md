# 藥袋二維碼資料格式

> 本文件整理「藥報平安」藥單範本所需的資料，說明藥袋二維碼（QR Code）要放哪些內容，掃描後才能直接建立藥單。
> 對應程式：`microservice/frontend/src/utils/qr.ts`（`parsePrescriptionQr`）

## 一、二維碼內容規則

- 二維碼內容**直接是一段 JSON 文字**（UTF-8），不是網址。
- 必須用「**靜態**」二維碼產生；動態二維碼（如 get-qr.com）只會放短網址，掃了無法建立藥單。
- 掃到不符合格式的內容時，畫面顯示「**掃描失敗**」，並列出讀到的內容或缺少的欄位。

## 二、藥單範本需要的資料

### 藥單（整張）

| 欄位 | 中文 | 必填 | 格式／範例 | 用在哪裡 | 沒填時 |
| --- | --- | --- | --- | --- | --- |
| `hospital` | 醫院／院區 | ✔ | `"仁愛院區"` | 藥單標頭、回診預約自動帶入院區 | 掃描失敗 |
| `department` | 科別 | | `"心臟科"` | 藥單標頭、回診預約自動帶入科別 | 只顯示院區 |
| `visitDate` | 看診（領藥）日 | | `"2026-11-08"`、`"2026/11/08"` 或民國 `"115.11.08"` | 從這天開始算還剩幾天 | 今天 |
| `days` | 給藥天數 | | `28` | 藥品沒有 `quantity` 時，用來推算總顆數 | 28 |
| `medicines` | 藥品清單 | ✔ | 陣列，至少 1 筆（見下表） | 藥品核對卡、時段、提醒 | 掃描失敗 |

> 藥單代碼（A、B、C…）與藥品代碼（A1、A2…）由 App 自動編號，不需放在二維碼裡。

### 藥品（`medicines` 每一筆）

| 欄位 | 中文 | 必填 | 格式／範例 | 用在哪裡 | 沒填時 |
| --- | --- | --- | --- | --- | --- |
| `name` | 藥名＋劑量 | ✔ | `"Aspirin 100 毫克"` | 藥品卡、朗讀、緊急醫療卡目前用藥 | 掃描失敗 |
| `amount` | 一次幾顆 | | `1`、`0.5`（以半顆為單位） | 顆數、每天吃幾顆 | 1 |
| `slots` | 什麼時候吃 | | `["早上","晚上"]`（早上／中午／晚上／睡前） | 四個時段、吃藥提醒（9:00／12:00／18:00／22:00） | 依 `frequency`，再沒有則早上 |
| `frequency` | 頻率代碼 | | `"TID"`（見下方對照表） | 沒有 `slots` 時換算成時段 | — |
| `meal` | 飯前／飯後 | | `"飯前"` 或 `"飯後"` | 藥品卡、朗讀 | 飯後 |
| `effect` | 功效 | | `"預防血栓"` | 藥品卡、朗讀、緊急醫療卡 | 空白 |
| `quantity` | 總顆數 | | `28` | **還剩幾天 = 剩下顆數 ÷ 每天吃幾顆** | `days` × 每天吃幾顆 |

### 頻率代碼 → 時段對照

| 代碼 | 意思 | 換算的時段 |
| --- | --- | --- |
| `QD`、`QAM` | 每天一次（早上） | 早上 |
| `QPM` | 每天晚上一次 | 晚上 |
| `HS`、`QN` | 睡前 | 睡前 |
| `BID`、`Q12H` | 每天兩次／每 12 小時 | 早上、晚上 |
| `TID`、`Q8H` | 每天三次／每 8 小時 | 早上、中午、晚上 |
| `QID`、`Q6H` | 每天四次／每 6 小時 | 早上、中午、晚上、睡前 |

> 同時有 `slots` 與 `frequency` 時以 `slots` 為準。

## 三、範例

### 最少必要資料

```json
{"hospital":"仁愛院區","medicines":[{"name":"Aspirin 100 毫克"}]}
```

→ 今天看診、早上吃 1 顆、飯後、28 顆。

### 完整資料

```json
{
  "hospital": "仁愛院區",
  "department": "心臟科",
  "visitDate": "2026-11-08",
  "days": 28,
  "medicines": [
    { "name": "Amlodipine 5 毫克", "amount": 1, "slots": ["早上"], "meal": "飯後", "effect": "降血壓", "quantity": 28 },
    { "name": "Metformin 500 毫克", "amount": 1, "frequency": "BID", "meal": "飯後", "effect": "降血糖", "quantity": 56 }
  ]
}
```

## 四、與現行藥袋「藥單內容」的對照

以使用者測試的藥袋二維碼為例：該二維碼內容是一張藥單圖片的網址（`scqa_drug_warning02.jpg`），圖片上的資料可對應如下。若要能直接掃描建立藥單，需請醫院把這些資料以上方 JSON 格式放進二維碼（或由後端讀取圖片後轉成此格式）。

| 藥單圖片上的欄位 | 範例 | 對應欄位 |
| --- | --- | --- |
| 醫院名稱 | 醫聖模範診所 | `hospital` |
| 科別 | 01 | `department` |
| 就診日 | 107.10.10 | `visitDate`：`"107.10.10"`（民國年可直接使用） |
| 藥品名稱及劑量 | Dl-methylephedrine | `medicines[].name` |
| 途徑 | 內服 | （目前未使用） |
| 數量（一次用量） | 1 | `medicines[].amount` |
| 服用方法 | 每八小時使用一次 | `medicines[].frequency`：`"Q8H"` → 早上、中午、晚上 |
| 總量 | 9.0 TB | `medicines[].quantity`：`9` |
| 天數 | 3 天 | `days`：`3` |
| 適應症 | 支氣管氣喘、蕁麻疹、過敏性疾病 | `medicines[].effect` |
| 副作用、警語 | 心悸、頭痛…／請勿開車 | （目前未使用，未來可加入藥品詳情） |
| 姓名、身分證、費用 | 金富貴、A88888****、50 元 | （藥單範本不需要；姓名與身分證屬個資，不建議放進二維碼） |

對應後的二維碼內容：

```json
{"hospital":"醫聖模範診所","department":"01","visitDate":"107.10.10","days":3,
 "medicines":[{"name":"Dl-methylephedrine","amount":1,"frequency":"Q8H","effect":"支氣管氣喘、蕁麻疹、過敏性疾病","quantity":9}]}
```

## 五、掃描失敗的情況

| 情況 | 畫面提示 |
| --- | --- |
| 內容不是 JSON（例如網址、一般文字） | 掃描失敗：這不是藥袋的二維碼，並列出讀到的內容 |
| 是 JSON 但缺少必填欄位 | 掃描失敗：藥單資料不完整，缺少：院區（hospital）／藥品清單（medicines）／藥名（medicines[].name） |
| 照片裡找不到二維碼 | 掃描失敗：這張照片裡找不到二維碼 |
| 相機 20 秒內沒掃到 | 掃描失敗：找不到二維碼，請靠近一點或改用上傳照片 |
| 瀏覽器不支援相機掃描 | 掃描失敗：請改用「上傳 QR Code 照片」 |
| App 掃描器沒有回傳結果 | 掃描失敗：沒有掃到二維碼 |
