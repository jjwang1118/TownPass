# seed/

Demo 與測試用的種子資料。規格書 §11.1。

除了健保用藥品項，**其他都是模擬資料**，藥袋內容需經藥師審核才能用於正式環境。繳交時要列在「資料來源清單」並註明為模擬資料。

## 檔案

| 路徑 | 內容 |
|---|---|
| `data/nhi_drugs.json.gz` | 健保用藥品項 45,224 筆（真實資料，由 `make_nhi_drugs.py` 產生），用於同成分檢查與藥名搜尋 |
| `data/rx_samples.json` | 範例藥袋 QR 的內容（一張藥單多個藥，格式見 `docs/qrcode_format.md`，含健保碼 `lic` 與總顆數） |
| `data/responders.json` | 模擬消防局名冊 4 筆（密碼匯入時以 argon2 雜湊） |
| `data/tpech_clinics.json` | 聯醫 7 院區、9 個院址（名稱、地址依聯醫官網）；各院址的科別（依院址特性簡化）、每科 2 位醫師的每週門診、每個看診時間的名額（模擬） |
| `qr/*.png` | 由 `rx_samples.json` 產生的 QR 圖檔，可以印出來或用另一支手機顯示給 App 掃 |
| `load.py` | 匯入資料庫，可以重複執行 |
| `make_qr.py` | 重新產生 `qr/*.png` |
| `make_nhi_drugs.py` | 把健保用藥品項 JSON 轉成 `data/nhi_drugs.json.gz`，見 `app/integrations/fda/README.md` |

## 範例藥袋

依序掃描，會配到藥單 A、B、C（對照 UI 的藥單 A、B）：

| 檔案 | 藥單 | 藥 | 示範 |
|---|---|---|---|
| `rx_a_cardiology.png` | 仁愛院區 心臟內科 王醫師，28 天 | A1 Amlodipine 5 毫克（脈優錠 `B021571100`）早上；A2 Aspirin 100 毫克（伯基 `A037344100`）早上；A3 Atorvastatin 20 毫克（立普妥 `B022890100`）睡前 | |
| `rx_b_metabolism.png` | 中興院區 新陳代謝科 陳醫師，28 天 | B1 Metformin 500 毫克（顧糖維 `B025635100`）早中晚；B2 Linagliptin 5 毫克（糖漸平 `B025537100`）中午 | 中午「B1、B2 各 1 顆」 |
| `rx_c_same_ingredient.png` | 和平院區 家醫科 林醫師，14 天 | C1 Amcopine 10 毫克（壓可平錠 `A047632100`）早上半顆 | 和 A1 不同牌子但同成分（ATC `C08CA01`），跳出「這兩包好像是同一種藥，請問藥師」 |

藥袋上的看診日是固定的（11/05、11/06），超過天數後藥單會自動移到「已吃完」；Demo 日期較晚時，修改 `rx_samples.json` 的 `date` 後重新產生 QR。

## 指令

在 `microservice/backend` 執行：

```bash
uv run python -m seed.load      # 匯入資料庫
uv run python -m seed.make_qr   # 修改 rx_samples.json 後重新產生 QR
```

## 救護人員帳號（模擬）

登入要選所屬分隊、輸入人員編號與密碼（UI R01）：

| 分隊 | 人員編號 | 密碼 | 姓名 | 狀態 |
|---|---|---|---|---|
| 大安分隊 | `000000` | `000000` | 測試人員 | 在職，可登入（Demo 用的簡易假帳密） |
| 大安分隊 | `A12345` | `demo-a12345` | 王大明 | 在職，可登入 |
| 中山分隊 | `A23456` | `demo-a23456` | 李小華 | 在職，可登入 |
| 信義分隊 | `A34567` | `demo-a34567` | 張志明 | **已離職**，登入顯示「無權限」（Demo 示範被擋） |

分隊清單與分隊電話 `02000000xx` 都是範例。舊版的 `EMT-001` 等帳號在重新匯入時會自動刪除（已有查看紀錄的保留）。

## Demo 順序（功能規格 2-5）

1. 路人用一般相機掃救命卡 QR：只看到「這位長輩有登記救命卡，請立即撥打 119」
2. 救護人員選大安分隊、用 A12345 登入，掃同一張卡：看到緊急醫療卡
3. 女兒手機收到「救護人員查看了王美玉的緊急醫療卡｜11/07 14:32｜臺北市政府消防局 大安分隊｜人員編號 A12345」
4. 用 A34567（信義分隊）登入：顯示「無權限」

## 聯醫門診（模擬）

- 門診從**執行匯入的隔天起**產生 2 週。用 `docker compose --profile app up -d` 啟動時每次都會自動匯入；用 uv 開發時，Demo 前一天要再執行一次 `seed.load`（已有的門診與預約不會被覆蓋）。
- 院區、科別、醫師的 id 固定（由名稱算出），重複匯入不會產生重複資料。
- 院區或科別改名、刪除後重新匯入，舊資料會自動移除；**已經有預約的門診不會刪除**，避免破壞預約紀錄。
- 科別依院址特性簡化：一般院址為家醫科、心臟內科、新陳代謝科、神經內科；婦幼為婦產科、小兒科；松德以精神科為主；林森加上中醫內科；昆明為一般內科、胃腸肝膽科、精神科。
- 每個門診有數個看診時間（每 30 分鐘一個），每個時間 8 個名額，並預先填入模擬的預約數（約 1/9 額滿），看診號碼接續發。
- 範例藥袋的醫師都在對應的院區與科別裡，掃藥袋後預約時「藥單的科別、醫師」會排第一。
- Demo 用：仁愛院區家醫科林醫師的第 1 個門診**額滿**、第 2 個門診**停診**。
- 地址請在 Demo 前與北市聯醫官網再核對一次。

長輩和家人的帳號不放在這裡：修改 App 的 `assets/mock_data/account.json`（`birthday`、`citizen`）即可切換。
