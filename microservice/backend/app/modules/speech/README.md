# speech — 朗讀稿

把結構化資料（編號、藥名、顆數、時段…）套進各語言的模板，產生交給手機 TTS 念的文字。只有 `rules.py`（純函式），沒有 API 和資料表。

**狀態**：🚧 第一階段：只有國語（`Lang.ZH`）（測試：`tests/test_rules.py`）

## 為什麼用模板，不用翻譯

朗讀稿是後端用資料組出來的，不是使用者打的自由文字。每種語言各寫一套模板，用同一份資料直接套出來：

- 內容固定、不會翻錯，對用藥資訊很重要
- 不需要呼叫翻譯 API，可離線

## 函式

| 函式 | 用在哪裡 | 例子 |
|---|---|---|
| `medication_card()` | 藥卡「念給我聽」（medication） | 1 號藥，脈優錠，家醫科開的，降血壓。一次 1 顆，飯後吃，早上 8 點。還剩 19 天。 |
| `reminder()` | 吃藥提醒推播與提醒畫面（reminder） | 陳阿嬤，吃藥時間到囉～飯後吃：1 號 脈優錠 2 顆、3 號 Metformin 500mg 1 顆 |
| `drug_name()` | 決定要念的藥名 | 見下方 |
| `speak_time()`、`qty_text()` | 時間、顆數的念法 | 早上 7 點半、1 顆半 |

## 藥名怎麼念

**有中文名就只念中文名，只有英文名就照原文念。** 依序找含中文的名稱：

1. 食藥署許可證的中文品名（`drug_licenses.name_zh`，用藥品的 `license_no` 查）
2. 藥袋上的藥名（`medications.name`）
3. 都沒有中文 → 念藥袋上的原文

科別、用途、稱呼仍去掉英文字母（例如「ENT 耳鼻喉科」念「耳鼻喉科」）。

吃藥提醒建立時會把要念的藥名存進 `reminder_events.items[].speech_name`，因為藥品停用後編號會被重用，之後重念同一筆提醒時藥名不會變。

## 之後加語言

1. 在 `Lang` 加上 `EN`、`NAN`（台語）
2. 在每個函式補上該語言的模板，並修改 `_ensure_supported`
3. 呼叫端加上要用的語言即可（例如依使用者偏好）

台語手機 TTS 大多不支援，發音方式（預錄片段拼接或外部台語 TTS）之後再決定。
